# 屏译通 用户手册

面向最终用户的操作说明。若需了解实现原理，请见 [架构说明](架构说明.md)。

---

## 一、这是什么

**屏译通**是一款 Windows 桌面实时翻译软件。它会自动识别屏幕上的外文内容，
把译文**直接显示在原文所在的位置**，你不用截图、不用框选、不用切换窗口，
就能像读母语一样阅读外文网页、软件界面和技术文档。

**与常见翻译工具的区别**：

| | 常见截图翻译工具 | 屏译通 |
| --- | --- | --- |
| 操作 | 手动截图 → 等待 → 对照查看 | 自动跟随，无需操作 |
| 译文位置 | 独立弹窗或侧边栏，需来回扫视 | **原位叠加**，视线不移动 |
| 数据去向 | 截图上传到云端服务器 | **全程本机处理，不联网** |
| 翻译能力 | 词库匹配，长句译文生硬 | 本地大模型，长句通顺 |

## 二、安装

**方式一：源码运行（推荐）**

```bash
python -m pip install -r requirements.txt --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu
python run.py
```

需要 Python 3.10 或更高版本。

> `llama-cpp-python` 从预编译 wheel 索引安装可避免本地编译
> （Windows 上从源码编译需要 MSVC 工具链）。

**方式二：安装包**（如已提供）

双击运行 `屏译通-Setup-x.x.x.exe`，按提示完成安装。

若提示缺少运行库，请先安装
[Microsoft Visual C++ 2015-2022 运行库](https://aka.ms/vs/17/release/vc_redist.x64.exe)。

### 推理运行时（随交付提供）

程序需要 `runtime/llama/llama-server.exe` 才能进行真实翻译。它已随交付目录
提供，**无需单独安装**。

若该目录为空（例如从版本库克隆时被排除），运行：

```bash
python scripts/download_runtime.py
```

查看安装位置与查找顺序：

```bash
python scripts/download_runtime.py --show-paths
```

### 便携模式

把配置、历史记录与模型都保存在程序目录下，不在系统盘留痕：

```bash
python run.py --portable
```

## 三、首次运行

1. 启动后程序**不会显示窗口**，而是最小化到系统托盘
   （任务栏右下角，可能在折叠区域里，点击 `^` 展开）。
2. **程序会自动加载模型**，右下角会提示"正在加载模型"，
   加载完成后提示"模型已就绪"。1.7B 模型约需数秒到十余秒
   （取决于硬盘速度），期间界面**不会卡住**，可以正常操作。
3. 双击托盘图标打开主设置面板。
4. 在「常规」分页选择**目标语言**（默认中文）：
   点开「目标语言」下拉框即可看到 142 种可选语言，列表里带 `✓`
   的是历史固定句双模型通过、`~` 是历史疑似、`✗` 是历史未通过；
   这些标记不保证每个翻译方向、OCR 或语义准确度。
   也可以直接键入中文名、英文名或母语名快速跳转
   （例如键入 `冰`、`ice` 都会跳到冰岛语）。
5. 选择**源语言**。自动识别适合中文、英文、日文及繁体；其他语言请手动指定。
   手动选择会使用相应脚本的离线 OCR。没有对应模型时会明确提示无法识别，
   不应把缺失识别或返回其他语言的结果当成正确译文。
6. 点击右上角 **开始翻译**。首次加载新的识别模型时会等待后台初始化。

### 识别与输出的边界

- 离线识别随包提供中英日、拉丁字母、韩文、西里尔字母、阿拉伯字母、
  天城文、希腊文、泰文、泰米尔文、泰卢固文和卡纳达文模型；
  有模型也可能漏字、识别错误，字体和画面清晰度会影响结果。
- 选定的目标语言会用于模型提示词、缓存和输出检查。明确的外语混入会尝试一次纠错；
  纠错仍不通过时保留原屏幕文字，不把坏结果写入译文缓存或历史。
- 同一文字脚本可能属于多种语言，短词及冷门语言无法完全自动验证。
  重要内容应对照原文核实，不能只依据语言名称或状态标记判断准确度。
- 使用在线 AI 时，待翻译文字会发送到配置的服务。填写 Key 后需启用在线功能。

### 模型是随程序附带的

Spark-X2.5 双模型的 GGUF 量化权重已随交付目录提供（`models/` 目录，
共约 3.45GB），**开箱即用，无需任何配置**。

- 极速模型（1.7B，1.03GB）在启动时自动加载；
- 高精度模型（4B，2.42GB）在首次需要时加载，之后空闲 180 秒会自动
  卸载以释放内存。

想确认模型加载状态，看设置面板「模型」分页：两个模型旁会显示
**已就绪 / 已加载 / 未就绪**，下方还会显示程序**实际找到的权重文件路径**。

### 如果提示"未找到模型权重"

说明 `models/` 目录里没有权重文件（例如从版本库克隆时被 `.gitignore`
排除了）。在项目目录下运行：

```bash
python scripts/download_models.py                # 下载两个模型
python scripts/download_models.py --model 1.7b   # 只要极速模型（推荐低配机器）
```

脚本支持断点续传、自动校验 SHA256、自动切换可用镜像。
下载完成后在设置面板点 **立即加载** 即可，不必重启程序。

### 关于"预览模式"

如果暂时不想下载权重（或下载未完成），程序会进入**预览模式**：

- 译文的位置、字号、换行、多屏适配**全部正常工作**；
- 但译文内容是 `〔未加载模型〕原文` 这样的占位标记。

这样可以先确认原位渲染效果符合预期，再去准备模型。
界面顶部状态条、托盘提示与通知都会明确标注当前处于预览模式，
**不会把占位内容伪装成翻译结果**。

## 四、日常使用

### 基本流程

开始翻译后，正常操作电脑即可。屏幕上的外文会自动被翻译，
译文出现在原文位置：

- 滚动网页时，译文跟随滚动实时更新；
- 切换软件界面时，新界面的文字自动被翻译；
- 静态界面不会重复翻译（画面没有变化时不做任何处理）。

**阅读中英混排的内容**时，建议切到「半透明叠加」模式
（设置 → 常规 → 显示模式），这样原文与译文叠在一起，便于对照。

### 暂停与恢复

三种方式任选：

- 按 `Ctrl+Alt+T`；
- 点击悬浮控制条上的 `▶` / `⏸` 按钮；
- 单击托盘图标。

### 实时译文文本框

点击悬浮栏最右侧的 **▾** 按钮，会在悬浮栏**正下方**展开一个文本框
（宽度与悬浮栏一致，35% 半透明底）：

- 屏幕上的译文会**实时汇总**显示在里面，按界面的阅读顺序排列
  （先左栏后右栏，栏内从上到下、行内从左到右），连起来读是通顺的；
- 面板**只向下展开，永不遮挡悬浮栏上方的屏幕内容**；悬浮栏贴近屏幕
  底部时高度自动收缩，想要更高的文本框就把悬浮栏往上拖；
- 展开时屏幕上的原位译文层暂时隐藏，避免同一段文字出现两遍；
  收起后自动恢复；
- 文本可以选中复制；内容更新时若你正在往下翻阅，不会被强行拽回底部。

再次点击（箭头变为 **▴**）收起。

### 语义精简

设置 → 常规 → 语言 → 「语义精简」。开启后译文在不改变语义的前提下
尽量缩短：省略客套话、冗余代词与重复限定，让屏幕上的译文更紧凑。

**边界**：只压缩措辞，不压缩信息——专业术语、学术词汇、专有名词、
数字、单位、代码标识符一律保留；否定、条件、数量、比较等改变论断的
成分不会被删。

### 全局热键

在任何软件中都可以使用：

| 热键 | 功能 |
| --- | --- |
| `Ctrl+Alt+T` | 开启 / 暂停实时翻译 |
| `Ctrl+Alt+M` | 切换极速 / 高精度模型 |
| `Ctrl+Alt+C` | 复制当前屏幕的翻译结果 |
| `Ctrl+Alt+H` | 隐藏 / 显示翻译层 |

**隐藏翻译层**（`Ctrl+Alt+H`）适合以下场景：需要看清屏幕原始内容、
要截图给同事看、或者要做演示。翻译仍在后台运行，再按一次即可恢复。

> 如果热键没有反应，可能是被其他软件占用了（常见于截图工具、
> 输入法、游戏加速器）。打开设置面板的「常规」分页会显示冲突提示。

### 悬浮控制条

屏幕下方的小长条，从左到右依次是：

| 元素 | 说明 |
| --- | --- |
| 圆点 + 文字 | 状态指示：绿点"翻译中" / 灰点"已暂停" |
| 极速 / 高精度 | 模型切换 |
| `▶` / `⏸` | 开始 / 暂停 |
| `▣` | 框选翻译区域 |
| `☰` | 打开翻译历史 |
| `⚙` | 打开设置面板 |

**按住控制条任意位置可以拖动**，位置会被记住。如果觉得碍事，
可以在设置面板的「常规」分页关闭它，只用热键操作。

## 五、让翻译更准确

### 选择合适的模型

| 场景 | 推荐 |
| --- | --- |
| 浏览网页、看软件界面、短句 | **极速 1.7B** |
| 读技术文档、学术论文、长段落 | **高精度 4B** |
| 不确定 / 希望自动 | **自动调度**（默认） |

自动调度会依据电脑负载与文本长度自行选择。当 CPU 占用过高或画面
开始卡顿时，它会自动切到 1.7B 以保证桌面流畅；负载降下来后再切回 4B。

> 低配电脑（8GB 内存）建议固定使用 1.7B：4B 模型约占 2.8GB 内存，
> 与系统和其他软件争抢内存反而会让整体变慢。

### 使用术语库

软件随安装包预装软件与 AI、医疗、生物、历史、物理、化学、数学七个领域的术语库，首次启动默认使用「软件与 AI」。设置 →「术语库」→「预装领域」可随时切换。全部词库使用双模型实测确认的 137 种语言范围；仅在源、目标语言都有明确本地化名称时应用术语，没有对应译名时不会猜译。

预装医疗等专业词条来源于社区数据，并非经过逐语专家审定，不能用于诊断、治疗等专业决策。对于法律、机械等尚未预装的领域，或客户有内部固定译法的情况，可导入自己的术语表。同一个术语在全文中会使用固定译名。

**方法**：

1. 准备一个 CSV 文件，两列分别为原文和译文：

   ```csv
   原文,译文
   machine learning,机器学习
   Spark-X2.5,讯飞星火 X2.5
   rate limiting,限流
   ```

   可以用 Excel 编辑，**另存为 CSV 格式**即可。

2. 打开设置 → 「术语库」分页 → 点击 **导入 CSV…**；
3. 选择文件，导入成功后会自动切到「自定义 CSV」。想恢复预装库时，点击「预装词库」，并在「预装领域」选择所需学科；再次切回自定义库时会沿用此前选择的文件。

**可选的高级设置**（第三、四列）：

```csv
原文,译文,区分大小写,整词匹配
GPU,图形处理器,是,是
inference,推理,否,否
```

- **区分大小写**：填"是"时只匹配 `GPU` 不匹配 `gpu`；
- **整词匹配**：填"是"时 `cat` 不会匹配到 `category`。
- **语言方向**：可再加第五、六列「源语言,目标语言」，例如 `en,zh`；留空则所有语言方向均适用。

设置面板的「术语库」分页有 **打开示例文件** 按钮，可以直接查看并
修改示例文件作为起点。

### 调整译文外观

设置 → 「样式」分页。**所有改动都会在上方预览区实时显示**，
不用切回桌面看效果。

| 设置 | 说明 |
| --- | --- |
| **显示模式** | 完全覆盖（遮住原文）/ 半透明叠加（对照阅读） |
| **字号模式** | 自动匹配原文（推荐）或固定字号 |
| **字号缩放** | 觉得译文偏小/偏大时调整 |
| **字体** | 只列出系统中确实可用的中文字体，避免出现方框 |
| **文字颜色** | 深色背景的软件用浅色字，浅色背景用深色字 |
| **遮罩颜色 / 不透明度** | 覆盖原文的背景 |
| **文字阴影** | 深色文字压在复杂背景上时更容易看清 |
| **最大行数** | 译文过长时截断并加省略号，避免遮住相邻内容 |

**调不好怎么办**：点「恢复默认样式」按钮。

### 只翻译部分屏幕

如果只想翻译某个软件窗口或网页的正文区域：

1. 点击悬浮控制条的 `▣`，或设置 → 常规 → **框选区域**；
2. 屏幕会变暗，**拖动鼠标框选**要翻译的区域；
3. 按 `Enter` 确认（或 `Esc` 取消）。

设好区域后，区域外的内容不会被识别与翻译，能明显降低资源占用，
也避免误翻译无关的文字。

**恢复全屏**：设置 → 常规 → 翻译区域 → 点击「框选区域」后按 `Esc`
退出，或者直接编辑配置文件把 `capture.mode` 改回 `fullscreen`。

## 六、翻译历史

设置 → 「历史」分页 → **打开历史记录…**，或按悬浮条的 `☰`。

- 表格显示时间、原文、译文、使用的模型；
- 顶部输入关键词可检索原文与译文；
- **导出 CSV / TXT** 按钮可把结果保存下来；
- **清空历史**会永久删除全部记录（需要二次确认）。

### 隐私提示

历史记录保存在你本机的数据库中，不会上传或同步。但请注意：

- 原文来自屏幕，**可能包含比译文更敏感的information**
  （内部系统路径、账号名、聊天内容等）；
- 如果介意，可以在设置 → 「历史」中关闭 **同时记录原文**，
  这样只保存译文；
- 也可以直接关闭 **记录翻译历史**。

## 七、设置说明

### 常规

| 项 | 说明 |
| --- | --- |
| 源语言 | 保持"自动检测"即可；识别不准时才手动指定 |
| 目标语言 | 译文要翻译成的语言 |
| 显示模式 | 完全覆盖 / 半透明叠加 |
| 翻译区域 | 全屏或框选区域 |
| 捕获帧率 | 默认 15fps。调低可省电，调高更跟手（但更耗 CPU） |
| 画面差分 | **建议保持开启**。关闭后每帧都整屏识别，CPU 占用会显著上升 |
| 启动后最小化到托盘 | 是否隐藏主窗口 |
| 显示通知 | 是否弹出右下角提示 |
| 减少动态效果 | 界面过渡更简短，去掉位移与缩放动画 |

### 模型

| 项 | 说明 |
| --- | --- |
| 调度模式 | 手动 / 自动调度 |
| 手动指定模型 | 仅在手动模式下生效 |
| 资源自适应 | 负载过高时自动降级，**建议开启** |
| 内容自适应 | 长句自动用高精度模型，**建议开启** |
| 批量翻译段数 | 多个片段合并推理。越大吞吐越高，但单次延迟也越大 |
| 推理缓存 | **建议开启**。界面文字重复率高，缓存能显著提速 |

### 关于

显示版本、开源组件清单与许可协议、隐私声明。
如需确认软件是否真的不联网，可以在这里查看技术说明。

## 八、卸载

### 安装包安装的

控制面板 → 程序和功能 → 找到"屏译通" → 卸载。

卸载时可以选择是否删除个人数据（配置、历史记录、模型文件）。
**模型文件较大（4GB 左右）**，若确定不再使用请一并删除。

### 数据文件位置

| 内容 | 路径 |
| --- | --- |
| 配置 | `%LOCALAPPDATA%\PingYiTong\config.json` |
| 历史数据库 | `%LOCALAPPDATA%\PingYiTong\data\history.db` |
| 日志 | `%LOCALAPPDATA%\PingYiTong\logs\` |
| 模型 | `%LOCALAPPDATA%\PingYiTong\models\` |

在文件资源管理器地址栏粘贴 `%LOCALAPPDATA%\PingYiTong` 即可打开。

## 九、故障排查

### 提示"未安装 RapidOCR，无法识别屏幕文字"

文字识别组件的依赖不完整。命令行执行：

```bash
python -m pip install rapidocr-onnxruntime
```

若下载缓慢，可使用国内镜像：

```bash
python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple rapidocr-onnxruntime
```

### 提示"未找到可用的模型权重"（预览模式）

模型文件没放对位置或文件名不匹配。

1. **先看设置面板**：「模型」分页的「模型文件位置」会显示程序**实际
   查找的结果**——是"未找到"还是某个具体路径，据此判断问题；
2. 最省事的办法是在项目目录运行下载脚本：

   ```bash
   python scripts/download_models.py
   ```

3. 已经手动下载了权重但仍显示"未找到"：把文件放进「默认下载目录」
   显示的那个路径即可。程序**容忍文件名差异**（大小写不同、带
   `-00001-of-00001` 之类后缀都能识别），通常不用改名；
4. 放好文件后点 **立即加载**，不必重启程序。

程序查找权重的完整顺序（先找到的优先）：

| 顺序 | 位置 |
| --- | --- |
| 1 | 环境变量 `PINGYITONG_MODELS_DIR` 指定的目录 |
| 2 | `<项目目录>\models\` |
| 3 | `%LOCALAPPDATA%\PingYiTong\models\` |

模型来源与规格见 [README 的"模型准备"一节](../README.md#模型准备)。

### 启动时模型加载很慢 / 界面卡住

模型加载在**后台线程**进行，界面不应卡住。若确实卡顿，可能是：

- **硬盘较慢**（机械硬盘）：1.03GB 权重读取需要十余秒，属正常；
- **内存不足**：加载时系统在换页。建议保持 4B 的预加载为关闭状态
  （配置文件 `model.accurate.preload` 为 `false`），
  或只保留极速模型；
- **杀毒软件实时扫描**：首次读取大文件时会被扫描，把 `models/`
  目录加入杀毒软件白名单可显著改善。

想跳过启动加载（例如只想先看看界面），可把配置文件中
`schedule.preload_on_start` 设为 `false`；此时模型在首次翻译时加载。

### 翻译层什么都不显示

按以下顺序排查：

1. 是否已点击「开始翻译」？（托盘图标应为彩色，状态显示"翻译中"）
2. 是否误按了 `Ctrl+Alt+H` 隐藏了翻译层？再按一次恢复。
3. 翻译区域是否设置得过小或位置不对？设置 → 常规 → 翻译区域改回全屏。
4. 目标语言是否与屏幕文字语言相同？相同则不会翻译（例如屏幕已是中文、
   目标也是中文）。**这种情况程序会在右下角弹出提示说明**，
   若提示"没有需要翻译的内容"，把目标语言改成别的语言即可。
5. 若是框选区域翻译，确认框选的位置和大小与预期一致；区域会按显示器
   缩放比例换算，150% 缩放的屏幕上框选 1068×852 对应物理 1602×1278。

### GPU 跑满但一直不翻译 / 内存占用异常高

先看任务管理器里有没有多个 `llama-server.exe` 进程。

正常情况下应当只有 1–2 个（每个模型一个）。如果出现好几个、
且内存占用接近上限，说明**之前有程序实例被强制结束**（任务管理器"结束任务"、
崩溃、断电），它拉起的推理进程没能一起退出，留了下来继续占资源。
这些残留进程会把内存与显存挤满，导致推理变慢甚至超时——表现就是
"GPU 跑满却什么都不翻译"。

处理办法：结束全部 `llama-server.exe` 进程后重新启动程序即可。

本版本已修复该问题：程序用 Windows 作业对象把推理进程绑在自己身上，
无论程序怎么退出（包括被强制结束），推理进程都会被一并终止；
启动时还会自动清理上一次遗留的残留进程，并提示
"已释放上次遗留的资源"。

### 译文位置偏了 / 跑到屏幕外面

多见于**多显示器且缩放比例不一致**的环境（例如主屏 100%、副屏 150%）。

1. 先尝试在显示设置里把两块屏的缩放比例设为一致；
2. 或者只在一块屏幕上使用（把待翻译窗口拖到主屏）；
3. 也可能是显示器热插拔后坐标缓存未更新 —— 重启程序即可。

### 译文挡住原文看不到了

- 改成「半透明叠加」模式（设置 → 常规 → 显示模式）；
- 或降低遮罩不透明度（设置 → 样式 → 遮罩不透明度）；
- 或按 `Ctrl+Alt+H` 临时隐藏翻译层。

### 电脑变卡

1. **切到极速模型**（`Ctrl+Alt+M` 或悬浮条切换）；
2. 调低捕获帧率（设置 → 常规 → 捕获帧率，可降到 8–10）；
3. 设为自动调度并确认"资源自适应"为开启状态；
4. **框选一个较小的翻译区域**，只翻译真正在看的部分（最有效的办法）；
5. 关闭「画面差分」的反面操作——**确保它是开启的**。

### 热键没反应

被其他软件占用了（常见于截图工具、输入法、录屏软件、游戏加速器）。

关闭可疑软件后重试，或编辑 `config.json` 的 `hotkey` 节改用其他组合键：

```json
"hotkey": {
  "toggle_translation": "Ctrl+Shift+F1",
  "switch_model": "Ctrl+Shift+F2"
}
```

### 程序启动后托盘找不到图标

Windows 默认会折叠不常用的托盘图标。点击任务栏右下角的 `^` 展开，
把屏译通的图标拖到可见区域即可固定。

### 想彻底确认软件不联网

1. 断开网络后启动并使用 —— 所有翻译功能应完整可用；
2. 用 Windows 防火墙把屏译通设为"阻止所有连接"，功能不受影响；
3. 打开任务管理器 → 性能 → 资源监视器 → 网络，观察是否有该进程的连接。

唯一的例外是首次运行 RapidOCR 时可能需要下载 ONNX 模型文件，
该下载完成后不再联网。

### 收集诊断信息

出问题时请提供日志文件（**日志不含屏幕识别内容**，可以安全分享）：

```
%LOCALAPPDATA%\PingYiTong\logs\pingyitong.log
```

以及以下信息：Windows 版本、放大镜缩放比例、显示器数量与各自分辨率、
是否安装 GPU、使用的是哪个模型。

## 十、常见问题

**问：能翻译视频字幕吗？**

本版本聚焦静态屏幕文字。视频字幕因为逐帧变化太快，会出现语义破碎
与闪烁，不属于当前版本的支持范围。

**问：支持 macOS / Linux 吗？**

当前仅支持 Windows。跨平台适配在规划中，需要替换屏幕捕获、
全局热键与透明窗口三处平台相关实现。

**问：可以翻译竖排文字（日文古籍）吗？**

当前按横排假设组织文本行，竖排文字的识别顺序会不正确。

**问：为什么有些数字、单位、代码没有被翻译？**

这是有意为之。程序在提示词中明确要求模型保留数字、单位、版本号、
URL、文件路径与代码标识符，因为翻译它们会破坏技术信息的准确性。

**问：同时在多块屏幕上用，会重复翻译吗？**

不会。每块屏幕有独立的翻译层，程序按坐标把译文分发到对应屏幕。
如果只想翻译其中一块，可在设置中指定显示器。

**问：翻译历史会不会泄露我的屏幕内容？**

历史保存在本机 SQLite 数据库中，不上传、不同步。
但原文确实来自你的屏幕，如需避免，可在设置中关闭"同时记录原文"
或完全关闭历史记录。

**问：可以只用它翻译某一种语言吗？**

源语言保持"自动检测"即可，程序会自行判断。首期支持中、英、日、韩、
法、德、俄、西 8 种语言。
