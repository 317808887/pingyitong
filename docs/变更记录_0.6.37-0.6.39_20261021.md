## 0.6.37（2026-10-19，r0005–r0009）

同一版本号的五轮候选尝试，不能按五轮计成五个发布版本。

- **r0005（partial）**：构建前复核未达完整性与准确性门槛，未构建安装。pytest 1501 passed + 1084 subtests。
  发现 Vulkan 双模型显存预算可能误走系统 RAM，转入后续候选修复。
- **r0006（partial）**：构建前真实模型复核发现精简译文新生语义错误，未构建安装。
  pytest 1607 passed + 1084 subtests。配对 84 项、发布 63 项、保留原文 21 项。
- **r0007（partial）**：v5 独立精简审核程序契约通过；但改动极速二审提示格式后完整度明显回退，
  改用兼容提示做单变量对照。pytest（最后单边界前）1640 passed + 1084 subtests；最终聚焦 339 passed + 3 subtests。
- **r0008（partial）**：兼容提示恢复完整度并开始构建；最终全套因夹具测试替身缺 Qt 坐标接口
  （`mapToGlobal` 等）出现 1 failed + 1648 passed + 1084 subtests。生产源码保留，问题留待 r9 修正测试替身后复用构建。
- **r0009（failed，真实安装）**：0.6.37 实际重新安装并经 Computer Use 鼠标启动。核心成果与实测：
  - 3 组原生场景 12 个场景实例，**38/38 行次识别**，未发现已分配文字/背景交叠；文字栏与复制完整。
  - 打包版 96 模块 + 20 OCR 资产核验；个人配置保留。
  - 实测时延：法→西首译 3089.8ms（回放 73.4ms）；英→日首译 17955.7ms、改数 2313.8ms、紧凑 13pt 缓存 503.3ms、最小字号 9px。
  - 未达标处：德语场景一行仅保留原文（完整性未过）；紧凑 13pt 最小 9px 日语不清楚；未交付任何独立审核通过的精简译文。
  - **实机发现观测计时起点错误**：约 289ms 的界面刷新曾被 UI 误报为 193 秒（invalidate 计时 epoch 问题），已在工作源码修正，留待 0.6.38 安装验证。
  - r9 复用 r8 逐字节相同的生产构建与模型结果（复用 84 项配对、发布 62 项：AI 等义 54/错 7/歧义 1/保留 22），新增模型调用 0 次。
