# 预装多领域术语库

`software_ai.json`、`medicine.json`、`biology.json`、`history.json`、`physics.json`、`chemistry.json` 和 `mathematics.json` 随软件和安装包分发。软件离线加载，不在客户设备上抓取网络术语。默认仍选「软件与 AI」；在设置 → 术语库中选择预装领域，或切换至自定义 CSV。

- 语言范围：屏译通已对 Spark-X2.5-1.7B 与 4B 逐语试译，并至少在其中一个模型上确认可用的 137 种语言。这里的范围不是模型官方提供的逐语清单。
- 本地化词条：软件与 AI 34 个概念，医疗 26 个，生物 28 个，历史 24 个，物理 20 个，化学 18 个，数学 20 个。每个概念只在源语言、目标语言都有明确名称时启用；缺名称的语言不凭模型猜译。不同领域分开选用，减少 `translation`、`solution` 等同形词跨学科误替换。
- 通用标准名词：软件与 AI 库中的 18 个协议、框架、格式与产品名称原样保留。
- 来源：Wikidata 相应 Q 编号实体的语言标签，结构化数据采用 [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing)。项目校订常见简体中文用语及少量英文同义写法。医疗等专业标签来自社区数据，**未经逐语医学或学科专家审定，不可作为诊断、治疗或专业决策依据**；客户应复核并可导入自己的 CSV 替换。
- 更新：运行 `python scripts/build_builtin_glossary.py` 更新软件与 AI 库；运行 `python scripts/build_domain_glossaries.py` 更新其余领域。两者均只用于构建期间，运行软件无需执行。发布前应检查 Q 编号对应概念及各语言标签差异。

CSV 自定义库保留原有四列格式 `原文,译文,区分大小写,整词匹配`。可选第 5、6 列 `源语言,目标语言` 用于限定语言方向；留空则应用到全部语言方向。应用内“专业术语库”页可在预装库与客户 CSV 间切换，也可导出当前库再修改。切换预装领域只改变本地配置，不删除客户 CSV。
