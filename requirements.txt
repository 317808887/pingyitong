# ---------------------------------------------------------------------------
# 大模型推理（重要：请先读下面的说明）
# ---------------------------------------------------------------------------
#
# ⚠️ Spark-X2.5 的模型架构为 `spark2_5`，**只有 XHToken 维护的 llama.cpp 分支
#    支持它**；上游 ggml-org/llama.cpp 不认识这个架构。而 llama-cpp-python
#    捆绑的是上游 llama.cpp，因此它**无法加载 Spark-X2.5 的 GGUF 权重**，
#    任何版本都一样（实测 0.3.35 报
#    `unknown model architecture: 'spark2_5'`）。
#
# 因此实际有两种推理后端，程序会自动选择（见 components/llm/backend.py）：
#
#   后端 A：llama-server 外部进程（**Spark-X2.5 的推荐方式**）
#     使用 XHToken 分支预编译的 llama-server 可执行文件，通过本机回环地址
#     与它通信。无需 C++ 编译器，支持 CPU / CUDA / Vulkan 三种后端。
#     获取方式：
#       python scripts/download_runtime.py
#     或手动从以下地址下载（由社区从 XHToken/llama.cpp 分支构建）：
#       https://github.com/dmitrysdm/llama-Spark-x2.5-win-x64/releases
#
#   后端 B：llama-cpp-python 进程内推理
#     适用于架构受上游支持的其他 GGUF 模型（如 Qwen、Llama 等）。
#     Spark-X2.5 用它会在加载阶段直接失败。
#
# 下面这一行保留 installer 的兼容性：若安装失败不影响后端 A 的使用。
# 安装时建议从预编译 wheel 索引安装以避免本地编译：
#   pip install llama-cpp-python \
#       --extra-index-url https://abetlen.github.io/llama-cpp-python/whl/cpu
llama-cpp-python>=0.2.20
